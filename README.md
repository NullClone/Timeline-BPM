# Timeline BPM

Unity Timeline 上で楽曲のテンポ（BPM）や拍子に応じたビートグリッド・小節グリッドを描画し、クリップやマーカーのスナップ操作を支援する Unity 拡張パッケージです。

---

## 主な機能

- **BPM / 拍子グリッド表示**:
  - 指定した BPM、拍子（1小節あたりの拍数）、基準時間（オフセット）に基づいて、タイムライン上に目盛り線を描画します。
  - 小節線（Bar）と拍線（Beat）を色や太さ・高さで視覚的に区別できます。
- **マグネットスナップ対応**:
  - クリップやマーカーのドラッグ操作時に、計算されたビートおよび小節の位置へ自動的にスナップ（吸着）します。
- **ズーム連動の間引き表示**:
  - タイムラインを縮小表示した際にグリッド線が密集しすぎないよう、表示幅に応じて自動的にステップ間隔を調整（拍間隔 → 小節間隔）します。
- **マルチトラック対応**:
  - 複数の BPM トラックを追加することで、楽曲の途中でテンポや拍子が変化する変拍子・テンポチェンジ演出にも対応可能です。

---

## 動作要件

- **Unity**: 2021.2 以降（Unity 6 / 6000.x 対応）
- **Timeline**: `com.unity.timeline` 1.8.0 以降

---

## インストール方法

### Package Manager (Git URL から追加)
1. Unity エディタのメニューから `Window` > `Package Manager` を開きます。
2. 左上の `+` ボタンをクリックし、`Add package from git URL...` を選択します。
3. 本リポジトリの Git URL を入力して追加します。

### ローカルパッケージとして追加
1. Package Manager の `+` ボタンから `Add package from disk...` を選択します。
2. 本フォルダ内の `package.json` を指定します。

## 使い方

1. Timeline ウィンドウを開きます。
2. トラック一覧の空白部分を右クリックするか、左上の `+` ボタンから **`Bpm Marker Track`** を追加します。
3. 追加したトラックを選択し、Inspector ウィンドウで設定を調整します。

### 設定項目 (Inspector)

| 項目 | 説明 | デフォルト値 |
| :--- | :--- | :--- |
| **BPM** | 楽曲のテンポ（1分間の拍数）。0 より大きい正数値を指定します。 | `120` |
| **Beats Per Bar** | 1小節あたりの拍数（例: 4拍子なら `4`、3拍子なら `3`）。 | `4` |
| **Beat Unit** | 1拍の音符の長さ（Quarter / 4分音符、Eighth / 8分音符 など）。 | `Quarter` |
| **Beat Origin (s)** | グリッドの開始オフセット秒数。楽曲の開始タイミングに合わせます。 | `0` |
| **Beat Color** | 拍（Beat）のグリッド線の表示色および不透明度。 | 薄い白 |
| **Bar Color** | 小節（Bar）のグリッド線の表示色および不透明度。 | やや強調された白 |

## 仕様・留意点

- **トラックのミュート**:
  - トラックをミュート（消音/非表示）にすると、グリッド描画およびスナップ処理が自動的に無効化されます。
- **スクロールアウト時のスナップ挙動**:
  - トラック数が増加して BPM トラックが画面外（上部や下部）にスクロールアウトした場合、スナップは一時的に無効となります。
  - これは Unity Timeline の標準仕様（画面内に可視化されている要素のみをスナップ対象とする空間分割設計）に準拠した動作です。
